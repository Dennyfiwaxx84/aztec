Aztec-Code Generator

Zwei individuell beschriftete Reiter in einem scannbaren Aztec-Code.

Die gleiche index.html muss dort veröffentlicht sein. Eine lokale file://-Adresse funktioniert auf fremden Handys nicht.

Lange Texte erzeugen sehr dichte Codes. Nutze für zuverlässiges Scannen kurze Inhalte und drucke den Code ausreichend groß.

Tippe auf einen Reiter, um den Inhalt anzuzeigen. Vorher wird kein Text angezeigt.
